# Corpus

## Contents

`corpus/` contains paired Wolfram-language and SymPy derivations from plasma
physics and teaching. The directory prefixes distinguish research-code and project
collections (`code-`, `proj-`), repository collections (`gh-`) and archived research
and teaching material (`nc-`, `archive-`). [Sources and credits](../SOURCES.md)
records their origin, contributors and licence information.

Notebook input cells are stored as text without saved output. Cells that could
not be converted are marked `(* UNCONVERTED CELL *)` in place. Byte-identical
duplicates and empty conversions are omitted.

Most research scripts exercise a narrow set of operations in depth. The TU Graz
coursework under `archive-tu` and `archive-old` is shallower but covers a wider mix
(`Solve`, `Integrate`, `DSolve`, `Factor`, `Eigenvalues`, `Limit`), which makes it a
useful test for any compatibility subset. Plot expressions are compared
symbolically where supported; this does not check rendered graphics. Unsupported
plotting operations remain explicit refusals.

## SymPy companions

Every `.wl` script has a `.py` companion. Most companions are generated by the
bounded translator in `fortsym_bench/wl_to_sympy.py`; manually translated
companions are retained. `translation-manifest.json` records
which companions are generated and the assignment and skipped-statement counts
for each script. Generated companions expose every binding the translator can
lower, so partial coverage is visible.

The native backend reads the original `.wl` file directly; the companions exist only
for the SymPy oracle. Rules for writing or correcting a companion are in
[TRANSLATION.md](../TRANSLATION.md).

## Writing a corpus pair

The Python side is a plain module that imports `sympy` and exposes `results()`:

```python
import sympy as sp

def results():
    x = sp.Symbol("x", real=True)
    return {
        "pythagorean": sp.simplify(sp.sin(x)**2 + sp.cos(x)**2),
        "derivative":  sp.diff(sp.exp(x**2), x),
    }
```

The Wolfram side assigns an association with the same names:

```wolfram
fortsymBenchResults = <|
  "pythagorean" -> Simplify[Sin[x]^2 + Cos[x]^2],
  "derivative"  -> D[Exp[x^2], x]
|>;
```

Both files of a pair must expose the same result names. Declare a non-default
comparison with a `COMPARE` dictionary in the Python file; see
[comparison](comparison.md). `corpus/mhd1d/00_example.{wl,py}` is a complete
example.

## Converting notebooks

`tools/nb2wl.wls` extracts the input cells of Mathematica notebooks as `InputForm`
text and discards outputs, formatting and stored results. Cells are held during
conversion, so nothing is evaluated.

```sh
NB_MANIFEST=manifest.tsv wolfram -script tools/nb2wl.wls
```

This is a format conversion only. It is not used by the harness, the tests or CI,
and converted scripts enter the comparison corpus. Available reference backends
check only the operations and bindings they support.
