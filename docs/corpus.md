# Corpus

## Contents

`corpus/` holds 384 Wolfram-language scripts in 73 project directories. The
directory prefix records where a script came from: `code-` and `proj-` for research
codes and projects, `gh-` for GitHub repositories, `nc-` and `archive-` for archived
research and teaching material. 235 scripts were converted from Mathematica
notebooks; cells that failed to convert (77 of 7278 input cells, about 1%) are kept
in place and marked `(* UNCONVERTED CELL *)`. Byte-identical duplicates and empty
results were dropped during ingestion.

Most research scripts exercise a narrow set of operations in depth. The TU Graz
coursework under `archive-tu` and `archive-old` is shallower but covers a wider mix
(`Solve`, `Integrate`, `DSolve`, `Factor`, `Eigenvalues`, `Limit`), which makes it a
useful test for any compatibility subset. The coursework also contains many `Plot`
calls; plotting is out of scope for fortsym, so those results are reported as
`unsupported`.

## SymPy companions

Every `.wl` script has a `.py` companion. 382 are generated by the bounded
translator in `fortsym_bench/wl_to_sympy.py`, one is a hand-expanded fixture, and one
is an original hand translation. Together they cover about 9,050 assignments; about
11,500 statements (control flow, side effects, plotting and other non-assignment
code) are not translated, and `translation-manifest.json` lists the counts per
script. Generated companions expose every binding the translator can lower, so a
partial companion cannot be mistaken for a complete one.

The native backend reads the original `.wl` file directly; the companions exist only
for the SymPy oracle. Rules for writing or correcting a companion are in
[TRANSLATION.md](../TRANSLATION.md).

## Writing a corpus pair

The Python side is a plain module that imports `sympy` and exposes `results()`:

```python
import sympy as sp

def results():
    x = sp.Symbol("x", real=True)
    return {
        "pythagorean": sp.simplify(sp.sin(x)**2 + sp.cos(x)**2),
        "derivative":  sp.diff(sp.exp(x**2), x),
    }
```

The Wolfram side assigns an association with the same names:

```wolfram
fortsymBenchResults = <|
  "pythagorean" -> Simplify[Sin[x]^2 + Cos[x]^2],
  "derivative"  -> D[Exp[x^2], x]
|>;
```

Both files of a pair must expose the same result names. Declare a non-default
comparison with a `COMPARE` dictionary in the Python file; see
[comparison](comparison.md). `corpus/mhd1d/00_example.{wl,py}` is a complete
example.

## Converting notebooks

`tools/nb2wl.wls` extracts the input cells of Mathematica notebooks as `InputForm`
text and discards outputs, formatting and stored results. Cells are held during
conversion, so nothing is evaluated.

```sh
NB_MANIFEST=manifest.tsv wolfram -script tools/nb2wl.wls
```

This is a format conversion only. It is not used by the harness, the tests or CI,
and every script it produces is checked by Mathics and SymPy.
